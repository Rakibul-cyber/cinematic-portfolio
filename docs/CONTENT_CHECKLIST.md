# Photographer Content and Asset Checklist

This checklist identifies material that will be requested as its implementation
phase approaches. Do not place confidential information or unpublished client
media in the repository without an agreed secure workflow.

## Brand and studio identity

- [ ] Public photographer/studio name and preferred capitalization
- [ ] Primary logo, alternate marks, and monochrome versions (prefer SVG)
- [ ] Brand usage guidance and any existing color/type references
- [ ] Short positioning statement or tagline
- [ ] Favicon/app icon source artwork

## Biography and portraits

- [ ] Short homepage biography
- [ ] Full About-page biography
- [ ] Professional portrait(s), with usage approval
- [ ] Location/service area and languages offered
- [ ] Relevant awards, publications, clients, or credentials that may be stated
- [ ] Behind-the-scenes imagery if desired

## Contact and social presence

- [ ] Public email address
- [ ] Public phone and/or WhatsApp number, including international format
- [ ] Studio/business address and rules for public display
- [ ] Instagram, YouTube, Vimeo, Facebook, LinkedIn, or other approved links
- [ ] Preferred inquiry response expectations and call to action

## Services and pricing

- [ ] Service names and short descriptions
- [ ] Detailed features/deliverables for each service
- [ ] Starting prices or decision to omit public pricing
- [ ] Service order and active/inactive state
- [ ] Geographic coverage and travel terms
- [ ] Inquiry project/service types and budget ranges

## Portfolio structure

- [ ] Portfolio category names and desired ordering
- [ ] Project titles, unique slugs, and categories
- [ ] Short and full project descriptions
- [ ] Project dates/locations and publish permissions
- [ ] Featured-project choices and ordering
- [ ] Credits for collaborators, vendors, and clients
- [ ] Per-project SEO title/description where available

## Photography assets

- [ ] Curated, publish-approved photographs (not entire RAW shoots)
- [ ] Highest-quality export available for preparing optimized web masters
- [ ] Intended cover/hero selection for each project
- [ ] Desired gallery order
- [ ] Meaningful alt-text context: subjects, setting, and purpose
- [ ] Correct orientation/crop preferences and focal-point notes
- [ ] Confirmation that client/model usage rights allow web publication

Avoid submitting RAW archives for website storage. The eventual media pipeline
will create responsive derivatives and remove embedded EXIF/GPS data.

## Video assets

- [ ] YouTube video links or provider video IDs, preferably unlisted as appropriate
- [ ] Video title, description, thumbnail, and duration
- [ ] Project relationship and desired ordering
- [ ] Publication/privacy status and embed permission
- [ ] Small optimized hero loop, only if one is genuinely needed
- [ ] Captions/transcripts where available for accessibility

## Testimonials and trust content

- [ ] Approved quote text
- [ ] Client display name and optional company/role
- [ ] Optional approved portrait/company mark
- [ ] Written permission to publish
- [ ] Featured status and preferred order

## Inquiry and CRM decisions

- [ ] Required versus optional inquiry fields
- [ ] Service types, budget bands, and referral-source choices
- [ ] Admin notification recipients
- [ ] Customer confirmation wording and response expectations
- [ ] Inquiry retention period and deletion/anonymization policy
- [ ] Existing inquiry data migration needs, if any

## Business and legal inputs

- [ ] Legal business/operator name
- [ ] Address and contact details required for the Impressum
- [ ] Legal form, authorized representative, and registration details if applicable
- [ ] VAT identification or business tax details if legally required for display
- [ ] Supervisory/professional information if applicable
- [ ] Privacy Policy inputs and approved final legal text
- [ ] Impressum inputs and approved final legal text
- [ ] Cookie/consent requirements identified by legal review
- [ ] Retention periods and data-subject request contact/process
- [ ] List of external processors and any required agreements

Legal text and compliance decisions should be reviewed by a qualified professional.
This checklist and the resulting software are not legal advice and do not by
themselves guarantee GDPR compliance.

## SEO and launch information

- [ ] Preferred site title and default meta description
- [ ] Canonical production domain
- [ ] Default Open Graph image
- [ ] Target locations and search topics stated naturally
- [ ] Search Console ownership/access
- [ ] Final social-sharing and structured-data business details
- [ ] Analytics and monitoring ownership/contact information
